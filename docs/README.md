# Maintainer documentation

Reference material for maintainers, contributors, and automation agents.
The [public README](../README.md) contains installation and package usage
instructions.

| Document | Contents |
| --- | --- |
| [Security policy](../SECURITY.md) | Private reporting, trust boundaries, and security requirements |
| [Configuration](configuration.md) | Public examples, local setup, and deployment-specific values |
| [Architecture](architecture.md) | Site rendering, architecture filtering, metadata, design, and assets |

| [Automation notes](automation.md) | Code entry points, preserved behavior, and checks for automated changes |
| [Validation records](validation.md) | Dated verification results and remaining runtime boundaries |

File paths in these documents are relative to the repository root unless stated
otherwise. Deployment-specific values belong in ignored local settings. Public
documents describe configuration fields and procedures rather than a deployed
instance.
